# 操作系统面试领域 Skill

## 领域提示
操作系统考察：进程与线程模型、调度算法、进程间通信、内存管理与虚拟内存(分页/页表/TLB/缺页)、文件系统与IO模型(阻塞/非阻塞/多路复用/异步)、锁与死锁、用户态与内核态切换。回答要求能落到内核机制与系统调用层面，并结合工程场景（如高并发IO、内存溢出排查）说明取舍。

## 考察点清单
- 进程/线程/协程的区别与切换开销来源
- 调度算法与优先级、CFS基本思想
- 进程间通信方式：管道、消息队列、共享内存、信号量、Socket
- 虚拟内存、分页与多级页表、TLB与缺页中断
- 内存分配与回收，OOM与swap的影响
- IO模型：阻塞/非阻塞/IO多路复用(select/poll/epoll)/异步IO
- epoll 边缘触发与水平触发的差异与使用约束
- 锁机制、死锁四个必要条件与排查手段
- 用户态与内核态切换代价及零拷贝
- 文件系统与页缓存、fsync与持久化语义

## 难度分级标准
- 1=能说出进程/线程差异与常见IO模型名称
- 2=能讲清一次系统调用与内存分配的主流程
- 3=能解释虚拟内存、页表与IO多路复用的工作机制
- 4=能结合线上问题（CPU飙高、内存泄漏、IO瓶颈）说明定位与优化
- 5=能推演极端场景（句柄耗尽、内存碎片、NUMA/大页）并给出体系化方案
