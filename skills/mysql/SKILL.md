# MySQL 面试领域 Skill

## 领域提示
MySQL面试覆盖：B+树索引与最左前缀、explain执行计划、事务隔离级别与MVCC、锁机制(行/间隙/Next-Key)、 redo/undo/binlog三套日志与两阶段提交、主从复制与延迟、分库分表与查询调优。回答需给出机制原因而非结论。

## 考察点清单
- 为什么用B+树而非哈希/红黑树
- 聚簇索引与二级索引、回表、覆盖索引
- 索引失效场景与最左前缀原则
- RC与RR区别、MVCC可见性判断
- 幻读如何解决、Next-Key锁加锁规则
- redo log保证持久性、binlog与主从
- 慢查询优化流程与分页深翻方案

## 难度分级标准
- 1=能说出概念与语法层面的结论
- 2=能阐述索引/事务/日志工作原理
- 3=能结合explain或例子分析执行路径
- 4=能对比隔离级别/方案差异说明Trade-off
- 5=能针对慢SQL、锁冲突、容量场景给出体系化调优方案
