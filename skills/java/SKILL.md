# Java 面试领域 Skill

## 领域提示
Java面试覆盖：JVM内存模型与GC、集合框架源码、并发编程(JMM/锁/线程池/AQS)、Spring(IoC/AOP/事务/Boot自动装配)、MyBatis原理。经典问题需追问到源码或参数级别才算有深度。

## 考察点清单
- JVM运行时数据区与OOM场景
- GC算法与收集器选型（G1/ZGC/CMS）
- HashMap/ConcurrentHashMap 底层结构与并发安全
- volatile/synchronized/锁升级/AQS/ThreadLocal
- 线程池7参数、拒绝策略与生产参数设置
- Spring Bean生命周期、循环依赖三级缓存
- 事务传播行为与失效场景
- Spring Boot 自动装配原理

## 难度分级标准
- 1=能说出概念定义与用途
- 2=能阐述工作原理与关键流程
- 3=能结合源码/参数讲清实现，并说明适用场景
- 4=能分析设计动机、对比替代方案并给出生产调优经验
- 5=能推演极端场景故障、吞吐瓶颈并给出体系化解决方案
