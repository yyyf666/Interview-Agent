# Redis 面试领域 Skill

## 领域提示
Redis面试覆盖：五大结构与底层编码(ziplist/listpack/skiplist/intset/quicklist)、持久化(RDB/AOF/混合)、过期删除与内存淘汰、主从复制与哨兵/Cluster高可用、缓存三类问题(穿透/击穿/雪崩)与一致性方案、分布式锁(Redisson/RedLock)、发布订阅与延迟队列。回答必须落到具体参数或编码名称。

## 考察点清单
- 数据结构底层编码与升级转换条件
- RDB与AOF原理、优缺点与生产配置
- 过期键删除策略与8种内存淘汰策略
- 缓存穿透/击穿/雪崩的成因与对策
- 缓存与数据库双写一致性方案对比
- 单线程模型与6.0多线程IO
- 持久化、复制与高可用架构
- 分布式锁的正确实现与坑

## 难度分级标准
- 1=能说出结构用途与常用命令
- 2=能阐述持久化/淘汰/复制机制原理
- 3=能结合编码转换条件、配置参数说明实现
- 4=能对比一致性/锁方案Trade-off并给出场景选型
- 5=能分析大key热key、集群扩缩容、故障恢复等生产实战
