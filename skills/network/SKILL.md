# 计算机网络面试领域 Skill

## 领域提示
计算机网络考察：TCP/IP分层与封装、TCP连接管理与可靠传输(三次握手/四次挥手/拥塞控制/重传)、UDP与QUIC、HTTP版本演进(1.1/2/3)、HTTPS与TLS握手、DNS解析、跨域与代理、常见排障思路。回答要求能讲清"为什么这样设计"与线上可观测证据（抓包、状态机、指标），而非只背流程图。

## 考察点清单
- 分层模型与一次请求的完整链路（DNS → TCP → TLS → HTTP → 代理）
- 三次握手/四次挥手的必要性、TIME_WAIT与CLOSE_WAIT成因
- TCP可靠传输：序号确认、超时重传、快速重传、滑动窗口
- 拥塞控制：慢启动/拥塞避免/快恢复，以及现代算法演进
- HTTP/1.1 队头阻塞与HTTP/2多路复用、HTTP/3基于QUIC的改进
- HTTPS与TLS握手流程、证书校验、对称与非对称加密分工
- HTTP缓存（强缓存/协商缓存）与CDN协作
- 网络排障：ping/telnet/curl/tcpdump 与连接状态观察
- 长连接保活、心跳与NAT超时的应对

## 难度分级标准
- 1=能说出分层模型与常见协议作用
- 2=能讲清一次HTTPS请求的完整过程
- 3=能解释握手/挥手细节与TCP可靠性机制的因果
- 4=能结合抓包与指标定位线上网络问题并给出优化方案
- 5=能推演高延迟/丢包/弱网场景下的协议行为并做架构级取舍
