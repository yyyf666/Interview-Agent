# 系统设计面试领域 Skill

## 领域提示
系统设计考察：需求澄清与容量估算、缓存架构、消息队列削峰解耦、分库分表、读写分离、限流熔断降级、幂等设计、分布式事务、秒杀/短链/Feed流等经典题。面试官必须先让候选人澄清需求与量级，再逐层展开，重点考察权衡而非标准答案。

## 考察点清单
- 是否先问清功能/非功能需求再做设计
- 容量估算：QPS/存储/带宽推导过程
- 缓存多层架构与一致性保障
- 异步化解耦与消息可靠性(不丢/不重/有序)
- 数据层扩展：分片键选择、热点处理
- 高可用：集群、故障转移、降级预案
- 幂等与分布式一致性方案选型

## 难度分级标准
- 1=能画出基本架构图并说明组件作用
- 2=能覆盖主要模块并说出常用中间件
- 3=能结合量级估算做技术选型并说明理由
- 4=能主动分析瓶颈、故障场景与Trade-off
- 5=能分层演进设计、处理热点/倾斜/容灾等极端场景
